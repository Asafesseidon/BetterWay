# BetterWay - Mapping System of the metro and train transport modals in Rio de Janeiro

BetterWay is a system created by me and Carlos Alberto to solve problems related to the lack of signalization on where the train and metro modals in Rio de Janeeiro intersect and their limits, to achieve this, we decided to map all the stations and connections of these two modals, and make an app that creates tracks based on the stations the user started(origin) and wants to reach(destination), for this app, Python alongside Jupyter and some Python libraries like NetworkX and Plotly as well as IPythonWidgets were used to display the map and tracks.
